# TanStack Start + TanStack Query + Tailwind CSS

A minimal [TanStack Start](https://tanstack.com/start) app with the [TanStack Query](https://tanstack.com/query) integration and [Tailwind CSS](https://tailwindcss.com). Formatting and linting use [Biome](https://biomejs.dev).

```bash
bun install && bun run dev
npm install && npm run dev
pnpm install && pnpm run dev
```
