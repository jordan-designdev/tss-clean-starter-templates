# TanStack Start + Base UI + Tailwind CSS

A minimal [TanStack Start](https://tanstack.com/start) app with [Base UI](https://base-ui.com) and [Tailwind CSS](https://tailwindcss.com). Formatting and linting use [Biome](https://biomejs.dev).

```bash
bun install && bun run dev
npm install && npm run dev
pnpm install && pnpm run dev
```
